# 樹木点検・外観診断アプリ

公園の樹木を、スマートフォン・タブレットで現地で **樹木点検** と **外観診断** をするためのWebアプリです。
点検の判定（有無）、外観診断（カルテの項目）、テープの案内、作業状況写真（デジタル黒板）、速報表（別紙1・別紙2）、総括表、診断カルテ（Excel）を作成します。通信のない場所でも使えます。

## ファイル

| ファイル | 内容 |
|---|---|
| index.html | アプリ本体（画面・プログラム・帳票の様式をすべて収録） |
| sw.js | オフラインで使うための仕組み（更新時は `VERSION` を変える） |
| manifest.webmanifest | ホーム画面に追加するための設定 |
| icon-192.png・icon-512.png | アイコン |

公開に必要なのはこの5ファイルだけです（README は任意）。

## 公開（GitHub Pages）

1. リポジトリ（Public）に上の5ファイルをアップロードします。
2. Settings → Pages で、Branch を `main`・フォルダを `/(root)` にして保存します。
3. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で開けます。

**樹木データ（Excel）や点検データ（ZIP）は、リポジトリにアップロードしないでください。** 樹木データはメールや庁内の共有フォルダで配り、各端末の「アプリの設定 → 樹木データ」で読み込みます。

## 更新するとき

`index.html` を直したら、`index.html` の `version` と `sw.js` の `VERSION` を新しい番号にしてアップロードします。各端末はアプリを開き直すと自動で新しい版に切り替わります。スタート画面の一番下に版（Ver）が表示されます。

**ホーム画面のアプリ（アイコン）は削除しないでください。** 端末内の点検データが消えることがあります。
