# 樹木点検アプリ

公園などの樹木を、タブレット・スマートフォンで現地点検するためのWebアプリです。点検結果・写真・作業記録を端末に保存し、速報（Excel）の作成・メール送信、フォルダ分けした保存ができます。通信のない場所でも使えます（オフライン対応）。

> 開発・改修を引き継ぐ方は、先に [引き継ぎ資料.md](引き継ぎ資料.md) をお読みください。

## ファイル構成

```
├── index.html               アプリ本体（画面・プログラム・設定 APP_CONFIG をこの1ファイルに収録）
├── sw.js                    オフライン用（アプリ・ライブラリ・地図を端末に保存する仕組み）
├── manifest.webmanifest     ホーム画面に追加するための設定
├── icon-192.png, icon-512.png
├── docs/
│   ├── 樹木データテンプレート.xlsx   樹木データの入力用（アプリからもダウンロード可）
│   ├── サンプル_樹木一覧.xlsx       サンプル公園（架空・40本）
│   └── *.png                         画面の例
├── tests/
│   ├── e2e.js               動作確認テスト（Playwright）
│   └── fixtures/sample-trees.json   テスト用の樹木データ（架空）
├── 引き継ぎ資料.md
└── LICENSE
```

## 公開する（GitHub Pages）

1. GitHub で新しいリポジトリを作り、このフォルダの中身をすべてアップロードします（`tests/` は任意）。**実際の樹木データ・点検データは絶対にアップロードしないでください**（GitHub Pages のページは、リポジトリを非公開にしても公開されます。`.gitignore` で主な名前は除外しています）。
2. **Settings → Pages → Build and deployment → Source** で「Deploy from a branch」、Branch を `main`・フォルダを `/ (root)` にして保存します。
3. 数分で `https://<ユーザー名>.github.io/<リポジトリ名>/` に公開されます。オフライン機能・現在地・カメラは https で公開したページで動きます。

## 事業に合わせて準備する

1. **樹木データ**：`docs/樹木データテンプレート.xlsx` に1本1行で記入します（樹木番号・樹種・区分・樹高・幹周・枝張・位置・公園名・エリア・場所・備考）。位置は緯度・経度か、平面直角座標（X・Y・座標系）で入力できます。
2. アプリの「設定・データ → 樹木データ → 管理者向け → Excelから配布用データを作成」で配布用ファイル（`樹木データ_〇〇.json`）を作ります。記入したExcelをそのまま配ってもかまいません。
3. 配布用ファイルを、メール・庁内の共有フォルダなど**インターネットに公開されない方法**で各点検員に渡します。
   - 一時的に追加するだけなら「Excelから樹木を追加」でも使えます（その端末だけに保存）。
4. **設定**：`index.html` 内の `APP_CONFIG`（アプリ名・項目名・初期の地図・点検項目・判定・マーキング指示など）を必要に応じて変更します。詳しくは引き継ぎ資料の「設定項目」を参照してください。

## タブレットの準備（通信のある場所で1回）

1. 公開したページを開き、点検員の名前を入力して開始します（アプリが端末に自動で保存されます）。
2. 「設定・データ → 樹木データを読み込む」で、配布された樹木データ（JSON または Excel）を選びます。樹木データは端末の中だけに保存されます。
3. 「設定・データ → オフラインで使う → 表示範囲の地図を保存」で、点検する範囲の背景地図を保存します。
4. ホーム画面に追加します（iPad：共有 →「ホーム画面に追加」／Android：メニュー →「アプリをインストール」）。現地ではアイコンから起動します。

## 主な機能

| 機能 | 内容 |
|---|---|
| 点検員 | 起動時に名前を入力。点検記録・写真に記録 |
| 地図 | 点の色分け（点検状況／樹種）、3D表示、背景地図（航空写真・淡色・標準・OSM）、現在地、検索・絞り込み（樹種・区分・公園名・エリア・未点検のみ） |
| 点検入力 | ボタン・プルダウン・複数選択・数値・自由記述（音声入力）・写真。必須項目が未入力だと保存できない。判定の目安、下書き保存、離れた場所での警告 |
| 写真 | コメント、書き込み（矢印・両矢印・丸・自由線・文字・鋼棒・寸法）、ファイル名＝日付_点検場所_樹木番号_樹種名_連番.jpg |
| マーキング指示 | 判定C・Dでテープの色・巻き方を指示し、実施チェックを必須に |
| 作業記録 | 所定の本数ごとにカメラを起動。撮り忘れを一覧に表示し後から撮影 |
| 点検一覧 | 日付・点検員・判定で絞り込み、Excel出力 |
| 速報 | 点検日と木を選んでExcel（＋写真ZIP）を作成しメール作成。パソコンは宛先・件名・本文・添付入りのメールファイル、スマホは共有メニュー（宛先は自動コピー） |
| データの保存 | 点検データ／写真／日付／作業記録／日付 のフォルダ構成で保存（パソコンは選んだフォルダ、スマホはZIP） |
| バックアップ | 全データ（点検記録・写真・作業記録・保管庫）を1ファイルに保存。未バックアップの件数を表示し、前日以前の分が残っていれば起動時に案内 |
| 集約 | 各点検員の点検データを書き出し・取り込みで統合。同じ木に別の記録があれば新しい方を表示し、もう一方は保管庫へ |
| 保管庫 | 削除した記録・外した写真・変更前の内容・取り込みで置き換わった記録・前回の点検回を保管。削除はできず、元に戻せる |
| 台帳にない木 | 位置を指定して点検 |
| オフライン | アプリ・地図を端末に保存（樹木データ・点検データは端末内のデータベース）。現在地は端末のGPSで表示。メール送信は通信のある場所で |

## 動作確認テスト

```
python3 -m http.server 8766        # このフォルダで
npm i playwright xlsx jszip         # 初回のみ（別のフォルダでも可）
PW_EXPERIMENTAL_SERVICE_WORKER_NETWORK_EVENTS=1 node tests/e2e.js   # 39項目を自動で確認
```
